# UI/UX Pro Max — Complete Design Reference

A comprehensive UI/UX reference. A collection of standalone HTML pages covering visual styles, color systems, typography, charts, design patterns, and engineering guidelines — built as a companion to the [UI/UX Pro Max](https://ui-ux-pro-max-skill.nextlevelbuilder.io/) Claude Code Plugin. Compiled using Claude.

**Live site:** [https://devanshutak25.github.io/ui-ux-ref/](https://devanshutak25.github.io/ui-ux-ref/)

## Related: UI/UX Pro Max Skill

This repository is the reference data behind the **[UI/UX Pro Max](https://github.com/anthropics/courses/tree/master/prompt_engineering_interactive_tutorial)** Claude Code skill — an AI-powered design intelligence system that helps you:

- Plan and build production-grade UIs in any of the 100 visual styles
- Pick color palettes, font pairings, and chart types for your specific product
- Generate style-authentic code with proper design tokens
- Review and improve existing interfaces

Install the skill in Claude Code to use this reference data directly in your workflow.

## Tech

- **Zero dependencies** — pure HTML + Tailwind CSS (via CDN)
- **No build step** — open any `.html` file directly in a browser
- Fonts: [Inter](https://fonts.google.com/specimen/Inter) + [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk)

## Usage

```bash
# Clone and open
git clone https://github.com/devanshutak25/ui-ux-ref.git
cd ui-ux-ref

# Open index page
open index.html
# or serve locally
npx serve .
```

Browse `samples/` to see individual style demos. Each is standalone — no server needed.
